# ERRSA Minecraft

Custom Minecraft server software, web services, and supporting resources for the **Embry-Riddle Resident Student Association (ERRSA) Minecraft Network**.

## Projects

### Minecraft Plugins

| Repository | Purpose |
| --- | --- |
| [ERRSAMCCore](https://github.com/DB-ERRSA/ERRSAMCCore) | Core server commands and integrations |
| [PlayerInitialization](https://github.com/DB-ERRSA/PlayerInitialization) | Player initialization and verification |
| [VIPBridge](https://github.com/DB-ERRSA/VIPBridge) | VIP-related integration |
| [EventBridge](https://github.com/DB-ERRSA/EventBridge) | Event-related integration |
| [Guilds](https://github.com/DB-ERRSA/Guilds) | Player guild system |
| [PlayerQuests](https://github.com/DB-ERRSA/PlayerQuests) | Player quests and blueprint functionality |
| [Rank-Progression](https://github.com/DB-ERRSA/Rank-Progression) | Rank progression |
| [BannerBuilder](https://github.com/DB-ERRSA/BannerBuilder) | Banner-building features |
| [ShulkerReroute](https://github.com/DB-ERRSA/ShulkerReroute) | Shulker routing from the End |
| [AutoUnlockPvPDrops](https://github.com/DB-ERRSA/AutoUnlockPvPDrops) | Automatic unlocking of PvP death drops |
